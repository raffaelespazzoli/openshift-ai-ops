- (dynamic) Raffa opened with a foundational question: what does alert correlation actually mean and why do we need it. Room walked through the 7-alerts-from-one-disk-failure example. Landed on: correlation is triage optimization, not diagnosis — group related alerts into one unit of work before spending LLM calls. Now drilling into the correlation logic itself.
- (outcome) Correlation design resolved. Alert correlation = triage optimization before LLM calls. Five-layer deterministic correlator: dedup → namespace+time → label overlap+time → subsystem dependency graph → Learning Store co-occurrence. Severity-based settling windows (critical 60s, warning 5m, info 10m), group escalates to highest member severity. Max group age = 3x settling window. Over-grouping preferred — orchestrator refines during diagnosis. Namespace promoted above generic labels as semantically richer signal. Raffa contributed the namespace dimension and severity-based windows.
- (dynamic) Raffa asked whether sprint-status is missing a project scaffolding story. Room quickly converged: Story 1.1 is overloaded — monorepo layout, shared contracts, state machine, DB migrations, Helm skeleton, and structured logger should be a separate Story 1.0 (pure plumbing, no user-visible behavior). Winston and Amelia drove it; John conceded once the dependency argument landed. Murat wants test infra decoupled too. Backend-only scaffolding — frontend deferred to Epic 5.
- (outcome) Integration test strategy resolved. Four layers: DB (testcontainers, fixture in 1.0), API (TestClient+testcontainers, fixture in 1.0), Pipeline (mocked LLM + real Postgres, built in 2.1), MCP (mock Streamable HTTP server, built in 2.1). No Kind clusters, no real OpenShift, no live LLMs in CI — ever. Eval harness (Epic 7) is operational validation, not CI. Murat drove it; Winston backed deferring MCP mock to Epic 2. Each story owns its own tests at the appropriate layer.

Distinct from eval harness (Epic 7) which scores diagnostic accuracy — E2E validates plumbing (pods talk, Streamable HTTP works, LLM flows through LangGraph to DB to SSE to browser).
