System Context C4 Level 1

Container View C4 Level 2

Five deployments in a single namespace. The backend collapses REST API, webhook receiver, and LangGraph agent pipeline into one Python process. Two MCP Server instances enforce the RBAC Airlock — diagnosis is read-only, remediation is read-write. Communication between backend and MCP servers uses Streamable HTTP transport.

Pipeline Flow AD-1

The core paradigm. Every alert enters the directed pipeline and flows through typed stages. The fast-path bypasses LLM diagnosis for known patterns. The RBAC Airlock separates diagnosis (read-only) from remediation (read-write). Re-challenge loops are bounded to prevent infinite cycling.

Deployment Topology

Single Helm chart, single namespace, no CRDs. PostgreSQL is a StatefulSet with PVC for durability. The RBAC Airlock is enforced by deploying two MCP Server instances with different ServiceAccounts — never by application-level access control.

Incident State Machine AD-19

Every incident follows one canonical state machine. Only the pipeline engine advances state; the API layer reads. The fast-path shortcut skips from queued to diagnosed.

stateDiagram-v2
    [*] --> received
    received --> correlating : alert arrives
    correlating --> queued : settling window closed
    queued --> diagnosing : dequeued by pipeline
    queued --> diagnosed : fast-path match
    diagnosing --> diagnosed : diagnosis complete
    diagnosed --> awaiting_approval : policy gate requires human
    diagnosed --> executing : auto-approved
    awaiting_approval --> executing : SRE approves
    awaiting_approval --> closed : SRE rejects
    executing --> observing : execution complete
    observing --> resolved : alert cleared
    observing --> failed : alert persists / rollback
    resolved --> [*]
    failed --> [*]
    closed --> [*]

Key Architecture Decisions

23 decisions fixing the invariants that keep independently-built epics from diverging. Each carries Binds (what it governs), Prevents (the divergence it stops), and a Rule (the enforceable constraint).

AD-1
Staged Pipeline Paradigm
Every stage has typed input/output contracts. Agents live inside stages, never between them. Fast-path and re-challenge are conditional edges.
AD-2
RBAC Airlock
cluster-reader for diagnosis, cluster-admin for remediation. Helm-configurable. Dry-run pre-flight catches permission gaps.
AD-3
Two Schema Domains
LangGraph owns langgraph_* tables. Everything else is application schema with application-owned migrations.
AD-4
Shared Types Module
All stage-boundary artifacts in backend/src/models/. Structured + unstructured fields coexist. The contract IS the shared types.
AD-5
Deterministic Correlation
Five-layer correlator (no LLM): dedup → namespace+time → labels+time → dependency graph → Learning Store. Over-group, refine in diagnosis.
AD-6
Severity-Based Settling
Critical=60s, Warning=5m, Info=10m. Group inherits shortest window. Max age = 3× window.
AD-7
Direct Per-Agent LLM Config
No centralized gateway. Each agent role has its own client. Model routing and semantic cache are middleware wrappers.
AD-8
Python + React/TS
Backend: Python (FastAPI + LangGraph). Frontend: React + TypeScript + PatternFly. MCP Server: Go (external).
AD-9
Five-Deployment Topology
backend, frontend, postgresql, mcp-readonly, mcp-readwrite. Backend collapses API + pipeline. MCP via Streamable HTTP.
AD-10
SSE + Path-Versioned REST
SSE for live pipeline updates. REST at /api/v1/ for CRUD. Frontend falls back to polling on SSE drop.
AD-11
In-Process Observability
/metrics via prometheus-client. ServiceMonitor in Helm. JSON logging to stdout. LangGraph tracing via checkpoints.
AD-12
OpenShift OAuth
Bearer tokens validated against OpenShift OAuth. Aligns with Console plugin migration path.
AD-13
Unified RAG via pgvector
Runbooks + RHOKP bundled at build time, indexed into pgvector tables. Same retrieval path. Skills are callable tools, not RAG.
AD-14
Monorepo Source Tree
backend/ (models/ is the leaf), frontend/, charts/, docs/. Directory layout mirrors the paradigm.
AD-15
Partial Evidence on MCP Timeout
evidence_gaps field on diagnosis. Skeptic must challenge gaps. Policy Gate blocks auto-exec when gaps exist.
AD-16
Execution Freshness Gate
Re-validate alert still firing before execution. Resolved webhooks don't cancel pipelines — freshness gate catches at execution.
AD-17
Cache Invalidation Fingerprint
Semantic cache keyed by OCP version + topology hash. Staleness detected at lookup. No background reconciler.
AD-18
Global Remediation Lock
PostgreSQL advisory lock. One remediation at a time. Survives pod restart. Configurable cooldown.
AD-19
Canonical State Machine
received→correlating→queued→diagnosing→diagnosed→awaiting_approval→executing→observing→resolved|failed. Pipeline advances; API reads.
AD-20
Case Record Schema Ownership
Learning Store module (db/) owns the schema. Correlation reads via pgvector similarity only — no schema changes.
AD-21
SSE Event Envelope
{event, data: {incident_id, stage, state, timestamp, payload}}. Dot-notation event names. Envelope in shared types.
AD-22
Semantic Cache in knowledge/
Single middleware in knowledge/. db/ provides storage; knowledge/ owns logic. No duplicate caches.
AD-23
Priority Queue Concurrency
SELECT FOR UPDATE SKIP LOCKED for dequeue. Conditional UPDATE for cancellation. No in-memory queue.
