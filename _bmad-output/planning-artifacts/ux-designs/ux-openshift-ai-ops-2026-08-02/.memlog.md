- (decision) Visual tone: clinical and calm. No urgency theatrics — an SRE at 2am needs clarity, not red flashing.
- (decision) Design system: PatternFly. Intentionally compatible with future OpenShift Console plugin (FR-23). UI components must map cleanly to Console plugin patterns.
- (decision) Color mode: both dark and light. Dark is likely primary for SRE usage context (late-night, low-light).
- (decision) Form factor: desktop-first (laptop primary). No mobile focus. Adaptive layout for future mobile adaptability — use responsive grid, no fixed widths.
- (decision) No reference tool — clean-slate design within PatternFly conventions.
- (decision) Information Architecture — four primary views: (1) Firing Alerts list (default landing), (1a) Resolved alerts toggle with configurable time window, (2) Alert Detail with workflow visualization (clickable steps showing agent conversation summaries), (3) Approval signal prominently surfaced in list + approval action in detail view, (4) Stats/Dashboard: alerts over time, diagnoses over time, resolutions over time, MTTR.
- (decision) Incident list granularity: individual alerts as rows, visually grouped under their parent Root-Cause Event. Each RCE becomes a collapsible group header; individual correlated alerts are rows beneath.
- (decision) Detail view workflow: horizontal pipeline (Triage → Diagnosis → Skeptic → Remediation → Execution → Outcome). Click a stage to expand details below. Maps to PatternFly ProgressStepper component.
- (decision) Approval signal: badge/counter in the navigation (e.g., 'Incidents (3)' showing count of items awaiting approval). No row-level tinting — keeps the list clean and clinical.
- (decision) Detail navigation: full-page with breadcrumb (Incidents > Alert Name). Gives full width for horizontal pipeline visualization. Console plugin will use same pattern.
- (decision) RCE groups: collapsed by default. Header shows RCE label + correlated alert count + highest severity badge. Expand to see individual alert rows.
- (decision) Stats view is dual-purpose: quick operational pulse for SREs (top-level health indicators) + reporting charts for team leads (time-series, MTTR, resolution rates). Read-only — no actions from this view.
- (decision) Expanded stage content: all elements (structured diagnosis object, evidence artifacts, agent conversation summary, confidence score) rendered in a clean layout. No clutter — clarity is king.
- (decision) Approval view (Remediation stage expanded when awaiting): remediation plan steps, dry-run confidence badge, Approve/Reject buttons. Streamlined — no excess context unless the SRE drills deeper.
- (assumption) Pipeline stage states: completed, active, awaiting, failed, skipped — five states cover all cases. (User did not object.)
- (decision) Fast-path display: full pipeline rendered with skipped stages greyed-out + a 'Fast-Path' badge on the alert. SRE can see the replay provenance at a glance.
