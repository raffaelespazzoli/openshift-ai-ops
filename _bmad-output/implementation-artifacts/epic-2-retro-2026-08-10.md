## What Didn't Go Well

### 1. Parallel Worktree Isolation Failure (CRITICAL — now fixed)

**Problem:** When Layer 2 (stories 2.3 + 2.4) ran in parallel, the `best-of-n-runner` subagents wrote to both their worktree AND the main working tree, causing file conflicts. Required two rollbacks and eventual sequential fallback. ~4 hours lost.

**Root cause:** The `best-of-n-runner` creates a worktree but doesn't sandbox file operations. The orchestrator was passing absolute paths to the original repository in subagent prompts, causing agents to read/write there instead of their worktree.

**Investigation:** Compared with vault-config-operator where "it worked" — found the same behavior exists there (agents also wrote to main worktree), but succeeded coincidentally because parallel stories touched non-overlapping Go packages.

**Fix applied (this retrospective session):**
- `phase-logic.md`: Added "Worktree Path Isolation (CRITICAL)" section with 3 rules
- `phase-logic.md`: Changed Step 1 + Step 2 prompt templates to use relative paths + WORKTREE ISOLATION block
- `phase-logic.md`: Added pre-merge verification (branch has commits, worktree is clean) and post-merge test verification
- `bmad-dev-story.toml`: Added `activation_steps_prepend` gate that resolves `{project-root}` from `git rev-parse --show-toplevel`
